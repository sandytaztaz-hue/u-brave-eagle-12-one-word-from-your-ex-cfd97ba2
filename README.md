Exactly one word: the word your ex would use to describe you, and nothing else.

This entry's word is **Underwhelming** — the flat, painfully honest verdict of someone who promised more than he delivered, admitted by the person it describes. It is funny because the entrant knows it, it stings because it is true, and it needs no explanation.

## Run

```sh
python3 main.py
```

The program writes the single word to `/output/entry.txt` (13 bytes, no trailing newline). It reads no input, uses no randomness, and produces byte-identical output on every run.
